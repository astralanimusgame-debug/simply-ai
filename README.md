# Simply AI — демо для Android

Учебное приложение «Как пользоваться ИИ (Claude)» на русском, английском и испанском.

## Что нового в версии 0.3

- В первом уроке — объяснение «Что такое чат»: один чат — одна тема, Claude помнит только свой чат.
- Бонусы двух видов. «Продолжение — в том же чате»: 3 шага, как найти прошлый чат, и запасная кнопка «Скопировать всё целиком». «Новый разговор»: кнопка «Открыть новый чат в Claude».
- Основная кнопка теперь называется «Открыть новый чат в Claude».

## Что нового в версии 0.2

- После выбора языка — экран регистрации: зачем входить и как выглядит вход через Google (3 шага), кнопка «Позже».
- Затем выбор профессии (или «Не работаю / на пенсии»). На главной — задание под вашу профессию, сменить можно в профиле.
- У бонусных заданий есть кнопки «Скопировать» и «Открыть Claude».
- «Назад» (и кнопка на телефоне) возвращает на один шаг: из урока 3 — в урок 2. В уроке есть «‹ Назад» и «Все уроки».
- «Продолжить» открывает урок, где вы остановились, на том же месте. Выбранные варианты и введённые данные сохраняются, даже если закрыть приложение.
- «Пройти урок заново» — у каждого пройденного урока (звезда остаётся).

## Что внутри демо

- Выбор языка при первом запуске (RU / EN / ES), смена в профиле.
- Бесплатное интро: 7 уроков с интерактивными мини-заданиями. Звёзды копятся в общий счёт.
- Карта курса: «Для жизни» ($4.99 + сертификат) и «Для работы» (пакеты профессий по $0.99).
- Вход через Google и оплата — **демо**: вход просит только имя, покупка открывается бесплатно.
- Кнопка «Открыть Claude» открывает claude.ai или приложение Claude. «Скопировать» кладёт текст в буфер обмена.

Всё содержимое приложения — один файл `app/src/main/assets/index.html`. Тексты уроков лежат в нём в объекте `C` (ru / en / es).

## Как получить APK (файл для установки на телефон)

### Способ 1 — через GitHub, без установки программ

1. Зарегистрируйтесь на github.com и создайте новый репозиторий (New repository).
2. Нажмите **uploading an existing file** и перетащите **все файлы и папки** этого проекта, включая папку `.github`.
3. Откройте вкладку **Actions**: сборка «Build APK» запустится сама (около 5 минут).
4. Когда появится зелёная галочка, откройте сборку и скачайте **SimplyAI-demo-apk** внизу страницы.
5. Распакуйте архив, перенесите `app-debug.apk` на телефон и откройте. Android попросит разрешить установку из этого источника.

Если папка `.github` не загрузилась (на некоторых компьютерах она скрыта), создайте в репозитории файл `.github/workflows/build-apk.yml` и вставьте туда содержимое одноимённого файла из проекта.

### Способ 2 — Android Studio

Откройте папку проекта в Android Studio → дождитесь синхронизации → **Build → Build APK(s)**.

## Что нужно для настоящей версии в Google Play

1. **Вход через Google** — Credential Manager + Firebase Authentication (нужен проект в Firebase и SHA-ключ приложения).
2. **Оплата** — Google Play Billing: товары «Для жизни» и «пакет профессии». Для проверки покупок лучше иметь небольшой сервер.
3. **Аккаунт разработчика Google Play** (разовый взнос) и подписанная release-сборка.
4. Окончательное название и иконка. «Simply AI» и `com.simplyai.app` — временные: перед публикацией проверьте, что название свободно.
5. Наполнение платных модулей — пока там только план заданий.

Приложение неофициальное: Claude — продукт компании Anthropic. Логотипы Anthropic и Claude в приложении не используются.
